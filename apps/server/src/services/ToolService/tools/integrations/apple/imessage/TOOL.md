# iMessage

Read, search, and send messages through macOS Messages with one capability tool.

**Tier:** standard
**Type:** builtin

## Operations

- `check`: Check whether iMessage access is available.
- `list_conversations`: List recent conversations.
- `read`: Read messages from a conversation.
- `search`: Search message history.
- `send`: Send a message.

The previous iMessage tool IDs remain permanent aliases for these operations.
